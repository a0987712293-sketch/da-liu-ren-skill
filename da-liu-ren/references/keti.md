# 九宗門與課體意涵

九宗門是取三傳的九種方法，課名即由取法而來。課名給的是**事情的態勢**，吉凶仍要配合類神判斷。

## 一、賊剋法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 元首 | 四課中只有一課上剋下 | 以尊制卑、名正言順。事由上而發，主動、先舉有利，利見上級、求官。 |
| 重審 | 四課中只有一課下賊上 | 以下犯上、事起於下。多反覆，須再三審慎；先難後易，宜守正、慢行。 |

## 二、比用法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 知一（比用） | 多課有剋，取與日干陰陽相同者 | 事有兩端、心有疑惑，須擇一而行；利同類、近處、合夥；失物在近、盜為熟人。 |

## 三、涉害法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 涉害 | 多課有剋且比用不能定，取涉歷受剋最深者 | 歷經艱難、阻滯多，事遲緩；孕產多遲；凡事宜耐心。 |
| 見機 | 涉害深淺相等，取臨孟（寅申巳亥）者 | 事有轉機，見機而作，宜快速應變。 |
| 察微 | 涉害相等且無孟，取臨仲（子午卯酉）者 | 事須細察，防暗中隱患。 |
| 綴瑕（復等） | 深淺、孟仲俱等，陽日取干上、陰日取支上 | 事態膠著，宜修補缺失、等待時機。 |

## 四、遙剋法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 蒿矢 | 四課無上下剋，課上神遙剋日干 | 禍自外來但力量弱，如蒿草作箭：有驚無大害，事多虛聲。 |
| 彈射 | 四課無上下剋，日干遙剋課上神 | 我去求事，力量遠而弱；事難速成，若遇金神（有鏃）則力量較實。 |

## 五、昴星法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 虎視轉蓬（陽日） | 四課全、無剋無遙剋 | 動盪不安、如蓬隨風；出行有險，事多變動，宜靜不宜動。 |
| 冬蛇掩目（陰日） | 同上 | 暗昧不明、隱伏；事不清楚，防暗中阻礙或欺瞞。 |

## 六、別責法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 別責（蕪淫） | 四課只有三課、無剋無遙剋 | 事有欠缺、須依附他人才成；婚姻主不正、有第三者；謀事須借力。 |

## 七、八專法

| 課名 | 成立 | 意涵 |
|---|---|---|
| 八專（帷薄不修） | 干支同位（甲寅、庚申、丁未、己未、癸丑日）、兩課無剋 | 內外不分、同類聚合；事主重複、混雜；家宅婚姻須防不正。 |

## 八、伏吟

| 課名 | 成立 | 意涵 |
|---|---|---|
| 伏吟（自任，陽日） | 月將與占時相同，天地盤同位 | 伏而不動、靜中待時；事遲滯，行人未動，失物在家；宜守舊。陽日自任其剛，事由己出。 |
| 伏吟（自信，陰日） | 同上 | 陰日自信其柔，事多隱忍、依人而動。 |
| 伏吟（不虞） | 伏吟而有剋（六乙、六癸日） | 靜中有變，出乎意料。 |
| 杜傳 | 伏吟初傳自刑 | 道路阻隔、事受阻塞，須另尋出路。 |

## 九、返吟

| 課名 | 成立 | 意涵 |
|---|---|---|
| 返吟（無依） | 月將與占時相沖，有剋 | 反覆動盪、事去復來、得而復失；行人速至，遠行速返；主變動、遷移。 |
| 返吟（無親・井欄射） | 返吟無剋（丁丑、丁未、己丑、己未、辛丑、辛未日） | 動而無依、孤立；事出意外，需靠自己。 |

## 三傳格局

| 格局 | 意涵 |
|---|---|
| 三合炎上（寅午戌） | 火局：文書、光明、急躁；依其對日干的六親論。 |
| 三合潤下（申子辰） | 水局：流動、智謀、陰私。 |
| 三合曲直（亥卯未） | 木局：生長、曲折、文章。 |
| 三合從革（巳酉丑） | 金局：變革、刑傷、決斷。 |
| 稼穡（三傳皆土） | 遲滯厚重、田宅、阻隔。 |
| 進茹 | 連珠順行，事向前進。 |
| 退茹 | 連珠逆行，事往回退，宜退守、追舊。 |
| 間傳 | 隔位而行，事有間隔、轉折。 |
| 三傳遞生 | 層層相生，事有助力。 |
| 三傳遞剋 | 層層相剋，事多阻撓、競爭。 |
| 傳財化鬼 | 因財生禍、貪小失大。 |
| 鬼化為印 | 壓力轉為名位、文書，利功名。 |
| 三傳見空 | 空處之事虛而不實；吉事落空，凶事亦解。 |
