# 大六壬解卦流程

解卦的根本：**課中每一個論斷都要落在具體的神將上**。先定用神，再看用神在課中的位置、旺衰、空亡、所乘天將、與日干的生剋，最後看三傳怎麼走。

## 0. 先讀懂排盤結果

| 項目 | 意義 |
|---|---|
| 日干 | 求占者本人（我） |
| 日支 | 對方、所問之事、家宅 |
| 第一課（干上神） | 我的現況、我的態度 |
| 第二課（干陰神） | 我暗中的狀況、我的後續 |
| 第三課（支上神） | 對方／事情的現況 |
| 第四課（支陰神） | 對方暗中的狀況、事情的內情 |
| 初傳（發用） | 事情的起因、開端 |
| 中傳 | 事情的經過、轉折 |
| 末傳 | 事情的結果、歸宿 |
| 六親 | 以日干為我：生我者父母、我生者子孫、剋我者官鬼、我剋者妻財、同我者兄弟 |
| 遁干 | 三傳所附旬中天干；遁得「空」即落旬空 |
| 旺衰 | 以月令論：旺 > 相 > 休 > 囚 > 死；旺相有力、休囚無力 |

## 1. 定類神（用神）

依占問查 `leishen.md`。一件事通常有兩層類神：
- **六親類神**：如求財看妻財、問病看官鬼、考試看父母。
- **天將類神**：如求財看青龍、問病看白虎、文書看朱雀。

找出類神在課中出現的位置：
- 在**三傳**：事情與之直接相關，力量大；在初傳最直接。
- 在**四課**不入傳：有其事而不成主軸。
- 課傳皆不見：其事難成或與所問無緣，可看類神在天地盤所臨之處（地盤方位）推其所在。

## 2. 看發用（初傳）

- 初傳是全課的樞紐，問「為什麼會有這件事」。
- 初傳旺相、乘吉將、生日干 → 開局有利。
- 初傳休囚、乘凶將、剋日干 → 開局有阻，或事由不善。
- 初傳**空亡** → 事多虛而不實、起而無果；但若問凶事（如官司、疾病），空亡反為凶事落空。
- 發用的九宗門本身有意涵（見 `keti.md`）。

## 3. 看三傳流轉

- **遞生入日**（三傳生干，或末傳生干）：事終得助。
- **遞剋日干**、**傳財化鬼**（初財末鬼）：始得利，終招禍，貪財惹事。
- **鬼化為印**（初鬼末父母）：先有壓力，終轉為文書、名位，利功名。
- **初傳生末、末傳回生初**（遞生入初）：事情首尾相顧，可循環推進。
- **三合局**：事有團體、牽連眾人；炎上（火）、潤下（水）、曲直（木）、從革（金）、稼穡（土）各依五行對日干的六親論。
- **進茹**：事向前推進，順；**退茹**：事往回退，宜守舊、追回舊事。
- **間傳**：事有間隔、隔一層才成。
- **末傳空亡**：結局落空；**中傳空亡**：中途斷，宜另起。

## 4. 看干支（主客、彼我）

- 干上神**生**日干：我得助、得利；**剋**日干：我受壓、有損。
- 支上神**生**日支：對方／事情順；**剋**日支：對方／事有損。
- 干上神剋支上神，或日干剋日支：我能制彼，主動有利。
- 支上神剋干上神，或日支剋日干：彼能制我，宜守不宜攻。
- 干支上神相生相合：彼我和睦，交易、婚姻、合作易成。
- 干上空亡：我心意不實、力不足；支上空亡：對方不實或事落空。

## 5. 看天將

- 吉將（貴人、六合、青龍、太常、太陰、天后）乘類神 → 類神之事有好的表現方式。
- 凶將（螣蛇、朱雀、勾陳、天空、白虎、玄武）乘類神 → 有驚、口舌、爭鬥、虛詐、傷病、暗失等干擾。
- 天將須配所乘地支論吉凶：將生神、神生將較吉；將剋神或神剋將較凶。細節見 `tianjiang.md`。
- **貴人順逆**：順佈事較順遂，逆佈多反覆。

## 6. 參年命（若有）

- 本命、行年上神**生**日干或為類神吉神 → 個人運勢助事。
- 本命、行年上神**剋**日干、乘白虎／螣蛇 → 本人當年氣運有阻。
- 行年臨空亡：該年此事虛而不實。

## 7. 應期（事情何時發生、何時有結果）

常用取法（擇與占事最相關者，並說明依據）：
- **類神出空**：類神落旬空者，待其出旬（下一旬）或填實（遇到該地支之日）而應。
- **沖動**：類神遇沖之日、之月而動。
- **末傳之日辰**：事之結局常應在末傳地支之日或月。
- **三合補全**：三傳缺一成合者，待缺者到來之日。
- **快慢**：返吟主速、伏吟主遲；類神旺相則近，休囚則遠；初傳臨孟（寅申巳亥）快、臨季（辰戌丑未）慢。

## 8. 寫結論

1. **一句話斷語**：「此事可成，但有小阻」「財可得，然得後有是非」…
2. **依據**：每點對應課中的具體神將與規則。
3. **建議**：依課中凶神的性質給具體對策（例：玄武發用→防財物遺失、注意文件；朱雀剋日→避免口舌、合約再審）。
4. **應期**：能推則推，並說明取法。
5. **提醒**：六壬為傳統術數，供參考；健康、法律、財務重大決定請諮詢專業。

## 常見陷阱

- 不要只看課名吉凶就下結論；同一課名在不同占問、不同類神下吉凶可以相反。
- 「空亡」對吉事是壞事，對凶事是好事。
- 官鬼對問功名是用神（吉），對問病是病神（凶），六親吉凶隨占事而定。
- 兄弟爻問財為劫財，問合夥、朋友則為同伴。
- 同一事重複起課只以第一課為準。
