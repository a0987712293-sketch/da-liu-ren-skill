# 占事類神速查

每類先找**六親類神**與**天將類神**，再依 interpretation.md 的步驟判斷。干為自己、支為對方或事。

## 求財、投資、生意

- 用神：**妻財**；天將：**青龍**（大財）、太常（衣食之財）、六合（交易）。
- 財爻旺相、入傳、不空，乘吉將 → 有財可得。
- 兄弟發用或兄弟旺 → 劫財、競爭、破耗。
- 財臨空亡 → 財不實、落空。
- 傳財化鬼（初財末鬼）→ 因財惹禍、得而有損。
- 子孫入傳生財 → 財有源頭，利長期經營。
- 玄武乘財 → 防詐騙、失竊；天空乘財 → 虛財、承諾不實。

## 事業、求職、面試、升遷

- 用神：**官鬼**（官職、工作）、**父母**（文書、合約、錄取通知）；天將：**貴人**（主管、面試官）、青龍（升遷）、朱雀（消息）。
- 官鬼旺相入傳、生父母或貴人臨干 → 有望。
- 子孫發用或子孫旺（傷官）→ 職位難得、與上司不合。
- 官鬼空亡 → 職缺不實或暫無。
- 干上神生日干、支上神生干 → 對方欣賞我。

## 考試、學業、文書

- 用神：**父母**（試卷、文書）；**官鬼**為功名、名次；天將：**朱雀**（文章、考運）。
- 父母旺相乘朱雀、官鬼生父母 → 考運佳。
- 妻財發用剋父母 → 文書受損、考試失利。
- 朱雀空亡 → 消息遲或無。

## 婚姻、感情

- 男占：**妻財**為妻／女方，**天后**為女；女占：**官鬼**為夫／男方，**青龍**為男。
- **六合**為媒妁、結合；太陰為暗中情愫。
- 干為己，支為對方：干支上神相生、相合 → 情投意合；相剋 → 有爭執。
- 類神空亡 → 對方無心或不實。
- 別責、八專課：防第三者、關係不正。
- 返吟：分合反覆；伏吟：關係停滯。

## 疾病、健康

- 用神：**官鬼**為病，**白虎**為病神；**子孫**為醫藥、救神；父母為病情之源（勞累）。
- 官鬼旺、乘白虎剋日 → 病重；官鬼休囚、空亡或子孫發用制鬼 → 可癒。
- 干為病人，支為病情：支剋干病重，干剋支病輕。
- 依官鬼五行推部位：木肝膽筋骨、火心血眼、土脾胃、金肺呼吸、水腎泌尿。
- **一律提醒就醫**，不以占卜代替診斷。

## 失物、尋人

- 失物：**妻財**為物，**玄武**為盜；看玄武所臨地盤推方向。
- 類神不空、入傳 → 可尋回；空亡 → 難尋。
- 伏吟：物在家中未出；返吟：物已遠移或速回。
- 知一課：盜為熟人、物在近處。
- 尋人、行人：支或類神（依關係：父母、子孫、兄弟、妻財、官鬼）；驛馬動則人在途中。

## 出行、旅遊、搬遷

- 看**驛馬**、**白虎**（道路）；支為所往之地。
- 干剋支、支上神生干 → 利往；支剋干 → 去處不利。
- 白虎乘凶神剋日 → 防交通意外、傷病；玄武 → 防失竊。
- 返吟利遠行速返；伏吟出行受阻、延遲。

## 官司、訴訟、糾紛

- 用神：**勾陳**（爭訟）、**朱雀**（訴狀、文書）、**官鬼**（官方、罰）；**貴人**為法官。
- 干為原告（我）、支為被告（彼）：干勝支我勝，支勝干彼勝。
- 官鬼空亡、子孫發用 → 訟事可解；勾陳臨干剋日 → 纏訟。
- 貴人順佈、臨干上生日 → 判決有利。
- 提醒：實際法律問題仍須諮詢律師。

## 合作、交易、談判

- 用神：**六合**（契約、交易）、**妻財**（利益）、**兄弟**（合夥人）。
- 干支上神相生相合 → 談判順利。
- 天空、玄武入傳 → 防虛詐。
- 元首課主動出擊有利；重審課宜謹慎多核實。

## 家宅、房屋

- 支為宅，干為人；**父母**為房屋、契書。
- 支上神生支、乘吉將 → 宅安；乘白虎、螣蛇 → 宅中不寧。
- 人宅相生（干支上神相生）→ 住得安穩。

## 等候消息、能否成事（通用）

- 看類神是否入傳、旺衰、空亡；末傳的狀態代表最後結果。
- 不知該用何類神時，以**初傳**為事、**末傳**為果、**干支**為彼我。
