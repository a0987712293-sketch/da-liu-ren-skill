# 大六壬起課與解卦

這個技能分兩段：**程式負責排盤**（確定性的計算，不要心算），**你負責解卦**（依課體、類神、天將綜合判斷）。

## 一、起課

腳本在 `scripts/liuren.py`（需要 `lunar_python`，畫圖需要 `Pillow`）。第一次用先裝：

```bash
pip install lunar_python pillow   # 受限環境加 --break-system-packages
```

依使用者給的資訊選一種起法：

| 情況 | 指令 |
|---|---|
| 沒給時間 → 以現在起課 | `python3 scripts/liuren.py -q "占問事項"` （預設台北時區，`--tz` 可改） |
| 給了時間（公曆） | `python3 scripts/liuren.py --date "2026-10-27 13:44" -q "…"` |
| 報時/報數起課（自定占時） | 加 `--hour 午`，覆寫占時地支 |
| 直接給日干支、占時、月將 | `python3 scripts/liuren.py --day 甲子 --hour 午 --general 亥` |
| 要看本命、行年 | 加 `--birth-year 1990 --gender 男` |
| 要排盤圖 | 加 `--png 輸出路徑.png`，再把圖片交給使用者 |
| 要機器可讀結果 | 加 `--json` |

其他選項：`--guiren daquan`（改用《六壬大全》「甲羊戊庚牛」貴人歌訣，預設為通行「甲戊庚牛羊」）、`--daynight 晝|夜`（強制晝夜貴，預設卯至申時為晝）、`--no-zi-rollover`（23 點後不換日，預設子初換日）。

使用者沒說占問時間時，用**現在**起課並註明時間；農曆日期或「昨晚」之類模糊時間，先換算成公曆再起課，換算不確定就問。

## 二、解卦流程

讀 `references/interpretation.md` 取得完整步驟與判斷要點；需要查表時再讀：
- `references/keti.md`：九宗門與常見課名、格局的意涵
- `references/tianjiang.md`：十二天將與常見神煞
- `references/leishen.md`：各類占事的類神、用神與看法

解讀順序（細節見 interpretation.md）：
1. **定類神**：依占問找用神（例：求財看妻財、青龍；考試看父母、朱雀；疾病看官鬼、白虎）。
2. **看發用（初傳）**：事之起因；初傳六親、天將、旺衰、是否空亡。
3. **看三傳流轉**：初→中→末是事情的經過與結局；遞生、遞剋、化鬼、化財等。
4. **看干支**：干上神為我（求占者），支上神為彼（對方/事/宅）；生剋關係決定主客。
5. **看課體與格局**：課名本身的吉凶傾向（見 keti.md）。
6. **參年命**（若有）：本命、行年上神與天將。
7. **綜合結論**：先給一句明確結論（偏吉／偏凶／有阻後成…），再分點說依據，最後給可行的建議與應期（若能推）。

## 三、輸出格式

給使用者的回覆依序包含：
1. **課式摘要**：時間、四柱、月將、課名、三傳（六親・遁干・支・天將）；有排盤圖就附上圖。
2. **斷語**：一句話結論。
3. **依據**：3～6 點，每點對應課中具體的神將（例：「初傳妻財戌乘六合，財由人合而來」）。
4. **建議與應期**。
5. 一行提醒：六壬為傳統術數，解讀僅供參考；健康、法律、財務等重大決定仍應諮詢專業人士。

## 注意

- 排盤一律跑腳本，不要自己推天地盤或三傳；腳本已與兩套獨立開源實作逐課比對過 720 課。
- 涉害、貴人晝夜、子時換日各派做法不同，腳本預設與選項見上；使用者指定派別就照用。
- 解讀時引用的每個論據都要能在課中找到；不要編造課中沒有的神將。
- 同一件事不宜反覆起課求不同答案；使用者重問時，提醒以第一課為準。
